## The mechanism (C1), in one paragraph
A record series for one logical id = the legacy v2.1/cycle2 record (chain base, no block) + one appended record per
later qualification. Each appended record carries `version_forward = {version_context, source_commit, kernel_digest,
record_digest, supersedes:{path, record_digest}}`. A checker selects the record whose `(source_commit, kernel_digest)`
equals the tree being verified — **never a global newest** — re-checks that record's self-digest, and validates the
whole chain. Missing / tampered / wrong-version / ambiguous-head / broken-chain / rollback / replay each fail
explicitly, no silent fallback. Proven on synthetic series and piloted live on C2-P10/PROFILE-FREEZE (legacy checker
untouched and still stale on this tree; v2.2 supersession selected for this tree and re-derives clean).
