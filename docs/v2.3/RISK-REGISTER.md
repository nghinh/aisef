## Notes

- **BUILD-REPRO-01** is a genuine supply-chain/reproducibility weakness worth fixing in v2.3: the project
  advertises "reproducible build" and "two independent rebuilds byte-identical". *Corrected 2026-11-21 (supersedes the
  first-day note "holds only when the rebuild host matches CI's Python", which was the wrong diagnosis):* it holds for
  fresh-checkout builds and fails for working trees with non-git modes. The v2.3 contract (W1-DESIGN §6) states the
  tested scope explicitly — four CI interpreters, fresh + perturbed copies, toolchain and zlib recorded per leg.
- No destructive or privileged action is taken to mitigate any risk here; remediations that touch repo
  settings, secrets, or backups are proposed for owner/admin action.
