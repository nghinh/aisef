# AISEF V2.1 backlog

Authority: the owner's V2 stable release charter (`docs/v2/V2-STABLE-RELEASE-CHARTER.md`, §1, §4, §21). An item here
does not block 2.0: it failed at least one condition of the release-blocker rule (§1) or the charter defers it (§4).
Every item keeps the §21 fields; the machine-readable register of all findings, the 2.0 blockers included, is
`closure-evidence/v2/release/V2-RELEASE-FINDINGS.json`. Rule columns: R1 deterministic reproducer, R2 affects the
shipped V2 runtime / artifact / an explicit 2.0 claim, R3 impact in the §1 list.
